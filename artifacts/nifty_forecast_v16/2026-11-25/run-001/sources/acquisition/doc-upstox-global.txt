class=row><div class="col col--12 markdown"><header><h1>Global Instruments Support</h1></header>
<p><strong>Effective 11 May 2026</strong></p>
<p>We are pleased to announce the availability of the Global Instruments file — a dedicated JSON file that provides instrument keys for global stock market indices and economic indicators. Use these keys with the existing Upstox market data APIs to retrieve live quotes and historical candle data for benchmarks such as GIFT NIFTY, Dow Jones, S&P 500, and more.</p>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id=whats-included>What's Included<a href=#whats-included class=hash-link aria-label="Direct link to What's Included" title="Direct link to What's Included" translate=no>​</a></h2>
<p>A new instruments file is now available:</p>
<ul>
<li class=""><a href=https://assets.upstox.com/market-quote/instruments/exchange/global.json.gz target=_blank rel="noopener noreferrer" class="">Global Instruments</a></li>
</ul>

Possible values: <code>20 Seconds</code>, <code>120 Seconds</code>, <code>900 Seconds</code>.<tr><td style=text-align:left>instrument_key<td style=text-align:left data-label=Type><span class="upx-chip upx-chip--type">string</span><td style=text-align:left data-label=Description>Unique identifier used across Upstox APIs. Format: <code>&lt;segment>|&lt;trading_symbol></code><tr><td style=text-align:left>trading_symbol<td style=text-align:left data-label=Type><span class="upx-chip upx-chip--type">string</span><td style=text-align:left data-label=Description>Trading symbol of the instrument (e.g., <code>SGX NIFTY</code>, <code>^DJI</code>, <code>BZUSD</code>).<tr><td style=text-align:left>start_time<td style=text-align:left data-label=Type><span class="upx-chip upx-chip--type">string</span><td style=text-align:left data-label=Description>Market open time in IST (e.g., <code>6.30AM Monday</code>).<tr><td style=text-align:left>end_time<td style=text-align:left data-label=Type><span class="upx-chip upx-chip--type">string</span><td style=text-align:left data-label=Description>Market close time in IST (e.g., <code>2.45AM Saturday</code>).<tr><td style=text-align:left>week_days<td style=text-align:left data-label=Type><span class="upx-chip upx-chip--type">string</span><td style=text-align:left data-label=Description>Active trading days (e.g., <code>Mon-Fri</code>, <code>Sun-Fri</code>).<tr><td style=text-align:left>mtf_enabled<td style=text-align:left data-label=Type><span class="upx-chip upx-chip--type">boolean</span><td style=text-align:left data-label=Description>MTF is not applicable for global instruments. Always <code>false</code>.</table></div>
<h2 class="anchor anchorTargetStickyNavbar_Vzrq" id=how-to-use-global-instrument-keys>How to Use Global Instrument Keys<a href=#how-to-use-global-instrument-keys class=hash-link aria-label="Direct link to How to Use Global Instrument Keys" title="Direct link to How to Use Global Instrument Keys" translate=no>​</a></h2>
<p>Use the <code>instrument_key</code> from the Global Instruments file with the following Upstox market data APIs:</p>
<ul>
<li class=""><strong><a class="" href=/developer/api-documentation/get-full-market-quote>Full Market Quote</a></strong> — Retrieve the live quote including LTP, OHLC, and volume data for a global index or indicator.</li>
<li class=""><strong><a class="" href=/developer/api-documentation/ltp-v3>LTP V3</a></strong> — Fetch only the last traded price for one or more global instruments in a lightweight response.</li>
<li class=""><strong><a class="" href=/developer/api-documentation/v3/get-historical-candle-data>Historical Candle Data V3</a></strong> — Query OHLCV candle data for global instruments across daily, weekly, or monthly intervals.</li>
<li class=""><strong><a class="" href=/developer/api-documentation/v3/get-intra-day-candle-data>Intraday Candle Data V3</a></strong> — Retrieve intraday candle data for global instruments at minute-level granularity.</li>
</ul>
