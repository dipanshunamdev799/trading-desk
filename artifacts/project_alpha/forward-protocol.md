# Project Alpha prospective observation protocol

Current status: **RESEARCH ONLY**, not PAPER TRADING or LIVE CANDIDATE. No primary strategy passed historical statistical and execution gates. A validated trading skill cannot be produced by renaming an unvalidated profile.

Freeze the rule/configuration/data-policy version before the next genuinely uninspected full exchange session. Do not describe October/November dates already studied as an untouched final test. Preserve every setup and every abstention. A diagnostic candidate may be recorded while operational action remains NO TRADE.

Measure latency using actual receipt/decision/order-event times. Distinguish frame clocks, quote-book clocks and last-trade time. Archive exact metadata, bid/ask, depth, Greeks with units, chain vintages, exchange phase and observed costs. Unknown or stale data causes an explicit rejection rather than disappearing from the opportunity denominator.

Before starting a formal evaluation, register the economically meaningful net effect and training-only variance. A rough independent-observation planning formula is `(1.96+0.84)^2*sigma_R^2/effect_R^2`, followed by conservative day/session clustering adjustment. For illustration,0.1R effect and1R standard deviation require about785 independent outcomes before a clustering allowance; this is a planning calculation, not evidence that the effect exists. The variance cannot be reliably estimated from three quote-replay trades.

The machine specification sets minimums of60 distinct sessions and200 eligible opportunities, then requires the larger powered target. These minimums are not proof of adequacy. At the observed sparse frequency, a statistically useful test can take considerably longer. Predetermine the review rule; do not stop when cumulative profit becomes attractive.

Historical promotion requires positive conservative option-premium expectancy and an uncertainty bound accounting for the fixed tested alternatives, incremental value over naive controls, adequate parameter/regime stability and operationally feasible whole-lot sizing. It also requires honest treatment of missing fills/unresolved risk and a broader point-in-time premium/quote sample. A high profit factor alone is insufficient.

Only a historical survivor qualifies for a formal paper-trading stage. Compare observed spreads, execution delay, missing/partial fills, charges and state drift with the model. Any change creates a new experiment version and a new evaluation boundary. A live candidate additionally needs passed forward/operational gates and explicit human approval. This project has not reached that decision.

One bounded observation can be collected with the existing capture script, and the diagnostic engine can read current candles/status. Continuous future observations require the collector to run during actual sessions; this document does not claim those future results already exist. No automatic schedule or broker order was installed.
